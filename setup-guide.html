📋はじめに

このガイドでは、受け取った2つのHTMLファイルを使って、あなた専用のフリップブックサイトを作ります。

受け取ったファイル（2つ）
  ├── admin.html   ← あなたが使う管理画面
  └── index.html   ← クライアントが見る閲覧ページ

ℹ️

使うサービスはすべて無料です Cloudflare Pages・Google Driveはすべて無料プランで使えます。GitHubは不要です。クレジットカードの登録も不要です。

1admin.html を自分用に書き換える

管理パスワードを自分だけの文字列に変更します。テキストエディタで2か所だけ書き換えます。

1
admin.html をテキストエディタで開く
Mac：admin.html を右クリック →「このアプリケーションで開く」→「テキストエディット」
Windows：admin.html を右クリック →「プログラムから開く」→「メモ帳」
💡

VSCode（Visual Studio Code）がある場合はそちらがおすすめです。色分けされて見やすくなります。

2
管理パスワードを変更する
Cmd+F（Windowsは Ctrl+F）で検索欄を開き、ADMIN_PASSWORD と入力して検索します。
変更前：
const ADMIN_PASSWORD = 'memoal2025';
変更後（自分だけのパスワードに）：
const ADMIN_PASSWORD = 'あなただけのパスワード';
🔐

パスワードは必ず変更してください デフォルトのパスワードは配布された全員が知っています。自分だけの文字列に変更してください。

3
ファイルを保存する
Cmd+S（Windowsは Ctrl+S）で保存してください。
※ クライアントIDはこの後のSTEP 3で取得してから記入します。今はパスワードだけ変更でOKです。

Workers & Pages を開く

「アプリケーションを作成する」ボタンを押してください。

ファイルを更新したいときは？ Cloudflareの管理画面で該当のPagesプロジェクトを開き、「デプロイ」→「アセットをアップロード」から新しいファイルをアップロードし直すだけです。URLは変わりません。

3Google Drive APIを設定する

アルバム画像を自分のGoogle Driveに自動保存するための設定です。手順が多いですが、一度やれば以後は不要です。

ℹ️

Google Cloud Consoleとは？ GoogleのAPIを管理する開発者向けサービスです。今回はGoogle Drive APIの「接続キー（クライアントID）」を取得するために使います。無料です。

1
Google Cloud Console にアクセス
👉 console.cloud.google.com を開きます。
普段使っているGoogleアカウント（Gmail）でログインしてください。
2
新しいプロジェクトを作成
画面上部の「プロジェクトを選択」→「新しいプロジェクト」をクリックします。
プロジェクト名（例：album-flipbook）を入力して「作成」を押します。
console.cloud.google.com / 新しいプロジェクト
新しいプロジェクト
プロジェクト名 *
album-flipbook
キャンセル
作成
3
Google Drive API を有効化
左メニュー「APIとサービス」→「ライブラリ」を開きます。
👉 console.cloud.google.com/apis/library/drive.googleapis.com
「Google Drive API」をクリック →「有効にする」を押します。
APIとサービス → ライブラリ
🔍 Google Drive API
📁
Google Drive API
Manage files in Google Drive
有効にする
4
OAuth 同意画面を設定
「APIとサービス」→「OAuth 同意画面」を開きます。
ユーザーの種類：「外部」を選択 →「作成」を押します。
項目入力内容
アプリ名例：アルバムフリップブック
ユーザーサポートメール自分のGmailアドレス
デベロッパーの連絡先自分のGmailアドレス
スコープ変更不要（そのまま次へ）
⚠️

テストユーザーの追加を忘れずに 「テストユーザー」の画面で「＋ ユーザーを追加」→ 自分のGmailアドレスを追加してください。これを忘れるとログイン時にエラーになります。

5
OAuthクライアントIDを作成する
「APIとサービス」→「認証情報」→「＋ 認証情報を作成」→「OAuth クライアント ID」をクリックします。
項目入力内容
アプリケーションの種類ウェブ アプリケーション
名前例：flipbook-web（何でもOK）
承認済みの JavaScript 生成元STEP2で発行されたCloudflareのURL
例：https://my-album-studio.pages.dev
※ 末尾の「/」は不要。ドメインだけ入力

「作成」を押すと クライアントID が表示されます。必ずコピーして保存してください。

OAuthクライアントを作成しました
✅ OAuthクライアントを作成しました
クライアントID（コピーして保存）
123456789012-abcdefghijklmnop.apps.googleusercontent.com
📋 コピー
6
admin.html にクライアントIDを記入してCloudflareに再アップロード
admin.html をテキストエディタで開き、YOUR_CLIENT_ID_HERE を検索して書き換えます。
変更前：
const GOOGLE_CLIENT_ID = 'YOUR_CLIENT_ID_HERE';
変更後（コピーしたIDを貼り付け）：
const GOOGLE_CLIENT_ID = '123456789-abcdefgh.apps.googleusercontent.com';

保存後、Cloudflareの管理画面から admin.html を再アップロードしてください。

💡

Cloudflareへの再アップロード手順
Cloudflareダッシュボード → Workers & Pages → 作成したプロジェクト → 「デプロイ」タブ → 「デプロイを作成」→ admin.html をアップロード

4動作確認
1
管理画面にアクセスしてログイン
https://（あなたのURL）/admin.html にアクセスして、設定したパスワードでログインします。
2
テスト用JPGをアップロード
適当なJPGファイルをドロップして、フリップブックのプレビューが表示されることを確認します。
3
「🌐 公開登録する」でGoogle Driveに接続
「公開登録する」→「📤 Google Driveにアップロード」を押します。
Googleアカウントのログイン画面が出たら許可してください。
「〇〇を公開登録しました！」と表示されれば設定完了です🎉
⚠️

「このアプリはGoogleで確認されていません」と表示される場合 「詳細」→「（アプリ名）に移動」をクリックして進んでください。自分で作成したアプリなので安全です。

🎉 セットアップ完了！これからの使い方

管理画面（admin.html）でJPGをアップロード → フリップ確認 → 公開登録
閲覧ページ（index.html）のURLをクライアントに共有するだけです。

ログインできない

💡

admin.htmlを書き換えた後にCloudflareに再アップロードしているか確認してください。

「redirect_uri_mismatch」エラーが出る

💡

Google Cloud ConsoleのOAuthクライアント設定で「承認済みの JavaScript 生成元」にCloudflareのURLが正しく登録されているか確認してください。登録後は最大5分かかります。

Cloudflareのデプロイが「失敗」になる

💡

ファイルが正しくアップロードされているか確認してください。admin.htmlとindex.htmlの2ファイルが必要です。

「このアプリはGoogleで確認されていません」と表示される

💡

「詳細」→「〇〇に移動（安全でないページ）」をクリックして進んでください。自分で作ったアプリなので問題ありません。

ファイルを更新したのに反映されない

💡

Cloudflareへの反映には数分かかります。少し待ってからブラウザを強制リロード（Cmd+Shift+R）してみてください。
